# Личный агент для Obsidian

Чат в боковой панели Obsidian с выбором модели: локальная Ollama или ChatGPT через Codex. Диалоги сохраняются в хранилище. Плагин работает только в настольной версии Obsidian.

## Установка

1. Скачайте [архив последней версии](https://github.com/Keksonator/obsidian-personal-knowledge-chat/releases/latest) и распакуйте папку `personal-knowledge-chat` в `<ваше хранилище>/.obsidian/plugins/`. В итоге рядом должны лежать `main.js`, `providers.js`, `installer.js`, `manifest.json` и `styles.css`.
2. В Obsidian откройте **Настройки → Сторонние плагины**, разрешите сторонние плагины и включите **Личный агент**. Если плагин не появился, перезапустите Obsidian.
3. Откройте чат кнопкой на левой панели или командой **Личный агент: Открыть чат**.

Для установки в другое хранилище откройте **Настройки → Личный агент → Другое хранилище → Выбрать папку** и укажите папку этого хранилища. Плагин скопирует свои файлы и добавит себя в список включённых плагинов. Затем перезапустите Obsidian с выбранным хранилищем. Чаты и настройки не переносятся. Если плагин там уже есть, его файлы не перезаписываются; для обновления используйте архив новой версии.

Плагин пока не опубликован в каталоге сторонних плагинов Obsidian. Установка выполняется из GitHub.

## Модели

**Локально.** Установите [Ollama](https://ollama.com/), запустите её и загрузите подходящую модель, например `ollama pull qwen2.5:1.5b` или `ollama pull deepseek-r1:1.5b`. В чате выберите **Локально · Ollama**, затем модель. Список обновляется кнопкой рядом с выбором модели. Локальная Ollama не требует подписки ChatGPT; загрузка модели требует места на диске.

**ChatGPT.** Нужен установленный Codex с поддержкой `app-server` и доступ через подписку ChatGPT. В настройках плагина нажмите **Войти**, завершите вход в браузере, затем в чате выберите **ChatGPT · Codex** и обновите список моделей. На Windows плагин ищет исполняемый файл Codex автоматически; если не находит, укажите путь в настройках. Вход плагина отдельный от входа в приложение Codex. Доступность моделей и лимиты определяются вашим аккаунтом; API-ключ не используется. Мы не обещаем бесплатный доступ к конкретной модели.

Enter отправляет сообщение, Shift+Enter добавляет строку. Кнопка остановки прерывает ожидание ответа. После ошибки текст остаётся в поле для повторной отправки.

## Скил «Создать шаблон»

В чате выберите режим **Создать шаблон** и опишите нужный шаблон. Агент подготовит Markdown и откроет окно проверки. Там можно изменить название и текст, затем нажать **Сохранить**. Если окно закрыто, его можно открыть снова кнопкой у ответа агента. Папка для новых шаблонов задаётся в настройках плагина (по умолчанию `Шаблоны`). Существующие файлы не перезаписываются.

Шаблоны создаются как обычные заметки Markdown; чтобы использовать их с встроенным плагином Obsidian «Шаблоны», укажите в его настройках ту же папку.

## Свои скилы

Откройте управление скилами кнопкой с волшебной палочкой в чате или через настройки плагина.

- **Создать вручную:** укажите название, инструкцию для агента и результат — ответ в чате или шаблон Markdown. Сохранённый скил появится в списке режимов чата.
- **Создать с ИИ:** опишите задачу, выберите результат и нажмите **Создать черновик**. Плагин использует модель, выбранную в чате, и откроет редактор с предложенным названием и инструкцией. Проверьте их и нажмите **Сохранить**. До этого скил не сохраняется.
- Скилы можно изменять и удалять через то же окно. Перед удалением запрашивается подтверждение. Они хранятся отдельно в каждом хранилище Obsidian.

Свои скилы задают инструкции модели. Они не запускают скрипты и не получают доступ к существующим заметкам. Если результат скила — шаблон, его запись по-прежнему требует проверки и подтверждения. Это не импорт и не исполнение файлов `SKILL.md` Codex.

## Конфиденциальность

- История хранится обычным текстом в `<хранилище>/.obsidian/plugins/personal-knowledge-chat/data.json`. При синхронизации хранилища этот файл тоже может синхронизироваться. Не публикуйте его.
- Перед первой отправкой каждого диалога в ChatGPT плагин запрашивает подтверждение. При переключении локального диалога на ChatGPT передаётся его успешная переписка. Заметки не передаются.
- При создании скила с помощью ChatGPT отдельно подтверждается отправка его описания в OpenAI. При локальной модели описание остаётся на компьютере.
- Данные входа Codex хранятся вне хранилища: `%LOCALAPPDATA%/PersonalKnowledgeChat/codex` в Windows или `~/.local/share/PersonalKnowledgeChat/codex` в других системах. Не публикуйте эту папку.
- Codex запускается в отдельной пустой папке с отключёнными инструментами и режимом только чтения. Плагин не читает и не изменяет существующие заметки; новый шаблон записывается только после вашего подтверждения. Старые чаты ChatGPT не импортируются.

## Если не работает

- **Нет локальных моделей:** проверьте, что Ollama запущена и модель загружена; затем обновите список.
- **Codex не найден:** укажите полный путь к исполняемому файлу в настройках плагина.
- **ChatGPT просит войти:** выполните вход через настройки плагина и обновите список моделей.
- **Плагин не появился в другом хранилище:** перезапустите Obsidian, проверьте папку `.obsidian/plugins/personal-knowledge-chat` и включение сторонних плагинов.

## Разработка

Исходники не требуют npm-пакетов или сборки. Проверки: `node --check main.js` и `node --check providers.js`. Плагин распространяется по лицензии [MIT](LICENSE).
